Autoclip

A personal video clipping tool

Autoclip turns long videos into short, vertical clips with burned-in captions. It picks the most active moments of a video, cuts them, and publishes the result to the operator’s own YouTube and TikTok accounts.

How it uses TikTok

Autoclip uses TikTok’s Content Posting API with the video.publish permission. The account owner signs in through TikTok’s own authorization screen and grants this permission. After that, Autoclip can post clips to that same account, and only when the owner runs a posting job. It does not read the owner’s videos, followers, messages, or any other account data.

Content

Autoclip only processes videos that the operator owns or has permission to use. Clips are created on the operator’s computer, and each clip is uploaded to TikTok only when the owner chooses to post it.
